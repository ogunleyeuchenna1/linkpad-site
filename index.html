Download for Windows Download for Android
Before you connect: Both devices need to be on the same trusted Wi-Fi network. On iPhone, scan the QR code shown by the PC with Camera, then tap the link to open LinkPad in Safari; no iPhone app is required. LinkPad transfers directly over local HTTP and does not provide end-to-end encryption, so avoid using it on public or untrusted networks. Windows may show a publisher warning because the installer is unsigned. Android may ask you to allow installation from your browser or file manager.
