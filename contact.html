Contact LinkPad

Have a question about pairing, file transfers, the Android app, or using LinkPad in an iPhone browser? Contact the founder directly.

Contact the founder

LinkPad is created by Ogunleye Uchenna, a full-stack developer and software engineer. For product enquiries, troubleshooting, accessibility feedback, or responsible reports about the website or app, email:

ogunleyeuchenna@gmail.com

Including your device type, Windows or Android version, the steps you took, and the exact error message can help make a support request easier to investigate. Do not send passwords, private files, pairing codes, or other sensitive information.

Before requesting technical help

  • Confirm that LinkPad is open on the Windows PC and both devices are on the same trusted Wi-Fi network.
  • Check that Windows Firewall permits LinkPad on private networks.
  • Scan the current QR code after restarting the PC app; the pairing code changes when the app restarts.
  • For downloads, check Android's Downloads/notifications or the browser's download list.
