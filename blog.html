File sharing · Windows · Android

How to transfer files from Android to Windows over Wi-Fi

A local-network approach to everyday phone and PC file transfers

Sending a photo or document from an Android phone to a Windows PC often turns into a small project: find a cable, send an email, sign into a cloud drive, or search for the right folder. When both devices are nearby and on the same trusted Wi-Fi network, a local transfer can be a more direct option.

1. Start LinkPad on the PC

Install and open LinkPad on Windows. The desktop app hosts the local connection and displays a QR code with the current pairing information. Keep the PC app running while you transfer.

2. Connect the phone to the same Wi-Fi

Make sure the phone and computer use the same network. Guest Wi-Fi and some office networks isolate devices, so a connection may fail even when both show Wi-Fi bars. If Windows asks, allow LinkPad through the firewall on private networks.

3. Scan and choose the file

Open LinkPad on Android and scan the PC's QR code. Once connected, choose Add a file and pick a photo, document, or other file. The interface shows upload progress so a large transfer does not look like it disappeared. LinkPad supports files up to 2 GB, subject to available disk space and network conditions.

4. Download and keep a copy

On the receiving device, use the activity entry to download the shared file. Android saves downloads in Downloads and can use a distinct filename when you download the same item again. Shared files on the PC are temporary and expire after 30 minutes, so save anything you need to keep.

Security reminder: LinkPad transfers over local HTTP and does not provide end-to-end encryption. Use a trusted private network and do not send sensitive files over public Wi-Fi.

QR pairing · iPhone · Safari

Connect an iPhone to a Windows PC with a QR code

Use the iPhone Camera and browser without installing an iPhone app

An iPhone can connect to LinkPad without a dedicated iOS app. The PC and iPhone need to be on the same trusted Wi-Fi network, and LinkPad must be open on the PC.

Open the iPhone Camera and point it at the QR code shown in LinkPad on Windows. Tap the notification to open the local LinkPad page in the browser. The QR code carries the PC address and current pairing code, so it avoids manually typing a network address. If the pairing code has changed because the PC app restarted, scan the newly displayed QR code again.

Once connected, use the browser page to share supported files and text. A connection can fail if a guest network blocks communication between devices or if a firewall blocks the PC. On public or untrusted Wi-Fi, avoid sending confidential information: the local connection is HTTP and is not end-to-end encrypted.

For Android users, the LinkPad app offers an in-app QR scan flow. See the four-step setup guide or visit the contact page for troubleshooting.

Phone keyboard · Windows productivity

Use your phone keyboard to type on a Windows PC

A simple way to enter text when your phone is already in your hand

Sometimes it is more convenient to type on the phone you are holding than reach for the PC keyboard. LinkPad can send text entered in its phone keyboard view to the currently focused Windows application over the local network.

First pair the phone and PC using LinkPad and keep both on the same Wi-Fi. On the computer, click the document, search box, or other application where the text should appear. Then open the Keyboard view on the phone, tap the typing field, and use the familiar on-screen keyboard.

Common special keys include Enter, Tab, Backspace, arrows, and modifiers such as Ctrl, Shift, Alt, and Windows. Modifier buttons can be used as shortcut toggles or as regular key presses. If typing appears in the wrong place, focus the intended PC window and reconnect if the session has expired.

Keyboard input is sent to the focused PC app, so check the destination before typing private text. LinkPad does not encrypt the local HTTP connection end to end; use it on a trusted network.
